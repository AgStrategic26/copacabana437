# Lançamento Copacabana 437

Landing page do lançamento na Av. Nossa Senhora de Copacabana, 437.
Site estático publicado pela Vercel (domínio: copacabana437.com.br).

- `index.html`: página
- `img/`: fotos
- IDs do Pixel do Meta e do GA4: constantes `PIXEL_ID` e `GA4_ID` no script do `index.html`
- E-mail que recebe os cadastros: `LEAD_EMAIL`
